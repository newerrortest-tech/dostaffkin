# Dostaffkin — домашняя работа № 6

Проект урока «Backend и деплой на продакшн». Основа — работа № 5, оформление и подключение карт сохранены.

## Функции

- Создание заявки: POST https://testologia.ru/delivery/create.
- Получение отправления: GET https://testologia.ru/delivery/info с параметром id.
- Номер, маршрут и статусы берутся из ответов сервера.
- Ошибки API показываются через alert; сообщения об обязательных полях — под полями.
- Стоимость, срок и сброс расчётов работают как в предыдущем уроке.

## Запуск и проверка

```bash
npm ci
npm start
npm run check
npm run build
```

Сборка в docs. Для GitHub Pages используйте ветку main и папку /docs. Базовый путь /dostaffkin/. Файл docs/404.html обеспечивает открытие страниц по прямым ссылкам.

## Проверки

Производственная сборка успешна, 6 тестов прошли. В тестах API и карты заменены тестовыми объектами. Реальный сервер testologia.ru из среды подготовки недоступен (Site Unavailable), поэтому реальную отправку и отслеживание необходимо проверить после публикации.

После загрузки откройте оформление, рассчитайте маршрут, заполните контакты и отправьте заявку. Скопируйте полученный номер в отслеживание и проверьте маршрут. Для сдачи: https://newerrortest-tech.github.io/dostaffkin/
