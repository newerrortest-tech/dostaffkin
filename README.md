# Dostaffkin — домашняя работа № 5

Angular-проект на основе шаблона romanitlogia/dostaffkin и заметок урока «Проект на Angular».

## Запуск

Нужна поддерживаемая Angular 21 версия Node.js (например, 24 LTS).

```bash
npm ci
npm start
```

Откройте адрес, который покажет сервер разработки. HTML-файлы Angular нельзя запускать двойным щелчком.

## Проверка и сборка

```bash
npm run check
npm run build
```

Сборка находится в `docs/`. Настройки для GitHub Pages: ветка `main`, папка `/docs`. Репозиторий должен называться `dostaffkin`, так как базовый путь сборки — `/dostaffkin/`. Для прямого открытия маршрутов сборка включает `404.html`.

## Функции урока

- Главная страница, оформление и отслеживание; общая шапка и Angular Router.
- Reactive Forms, шесть размеров, два варианта скорости.
- Приоритетная доставка: +15% стоимости, −30% срока, округление вверх.
- При изменении параметров маршрута результат сбрасывается.
- Карты подключены через преподавательский `ymc_min.js` с ключами принятой работы.
- Отправка заявки демонстрационная: объект выводится в консоль, номер отправления — 1.
- Отслеживание демонстрационное, с маршрутом Москва — Минск и статусами из урока. Бэкенд и сохранение заказов не добавлены.
